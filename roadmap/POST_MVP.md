# Post-MVP Roadmap (Ranked)

Only expand after **D1 / bounce** look healthy.

| Priority | Feature | Call | Why |
|---|---|---|---|
| P1 | Difficulty tiers | Keep | Extends skill without new maps |
| P1 | Light permanent unlocks (cosmetics / mild power) | Reshape small | Return hook; don’t paywall power |
| P1 | Daily seeded tower | Keep (trend bet) | Friend co-play / shared challenge |
| P2 | Weekly co-op leaderboards | Keep | Social competition |
| P2 | More towers | Keep | Content roadmap |
| P2 | Cosmetics Game Passes / products | Keep | Monetize without gating first win |
| P3 | Seasons / LiveOps events | Keep | Retention cadence |
| P3 | Heist mode | Reshape or cut | Only if extract fantasy needs a second mode |
| — | Anime-style deep grind RPG | Avoid as core | Wrong genre for this loop |

## Soft-launch checklist (when publishing)
- Accurate title + description  
- Genre/subgenre = Action or Survival core loop  
- 2–5 thumbnails (real gameplay)  
- No Robux/giveaway bait  
- Watch Home Recommendations: bounce &lt;60s, D1 return, co-play
