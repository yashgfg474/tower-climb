# Tower Climb — Full Game Explanation

## Pitch (one sentence)
1–4 player **co-op tower climb** with **real-time combat** (swords, guns, powers): after each floor, **cash out with loot** or **risk climbing higher**, with a **random upgrade** per floor and a **boss** at the top.

## What it is / is not
| Is | Is not |
|---|---|
| Real-time action combat | Card battler / Slay the Spire clone |
| Short run (target **under 20 minutes**) | Open-world RP or anime grind RPG as v1 |
| Risk/reward extract fantasy | Pure endless runner |
| Co-op intentional (parties 1–4) | Solo-only competitive ladder first |

## Core loop
1. **Enter** a tower run (solo or party of up to 4).
2. **Clear a floor** with melee / ranged / powers against enemies.
3. **Decision:** cash out (keep loot) **or** climb (risk it for better rewards).
4. **Upgrade:** random upgrade offered each floor (reward for continuing).
5. Repeat through **4–6 floors**, then **boss**.
6. **Extract or wipe** → short session ends → reason to run again (better loot, try boss, play with friends).

## Session fantasy
- Feel: boys-type **action / survival** pressure — fight up, greed vs safety.
- Hook in **first 60 seconds:** spawn → fight → see cash-out vs climb clearly (no long lobby lore).
- Shareable moment: big **extract win** or **greed wipe** (good for Shorts/TikTok later).

## Combat (design intent)
- **Melee:** close-range sword-style.
- **Ranged:** gun-style pressure.
- **Powers:** few abilities that change a floor fight (not a huge ability tree in MVP).
- Server-authoritative damage, loot, and cash-out (Roblox pro rule: never trust the client).

## Floors & tower
- **Week 1:** one tower, 4–6 floors + 1 boss.
- Floors should read visually as “we climbed” (vertical progress, clear exit/cash-out UI).
- Boss = climax of the greed curve.

## Social / co-op
- Parties **1–4**.
- **Dead players spectate** teammates (keeps co-play and reduces rage-quit bounce).
- Later trend bet: **daily seeded tower** (same seed for friends) — post-MVP.

## Audience & platform
- Primary feel: action/survival for a younger male-leaning Roblox action crowd.
- Still design **mobile-first** HUD (most Roblox play is on phones).
- Creator Hub genre should be **core loop** (Action or Survival), not a theme tag like “horror.”

## Monetization philosophy
- **Do not gate the first win.**
- Monetization is **later**: Game Passes, developer products, cosmetics — convenience/cosmetics over pay-to-ruin.
