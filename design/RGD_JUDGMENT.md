# RGD Judgment — Trends & Changes (2026)

## Scorecard
| Lens | Score | Note |
|---|---|---|
| Retention fit (RFY 2026) | Strong | Short runs, return tomorrow, co-play weighted |
| Clarity of core verb | Strong if first 60s is fight→cash-out | Must not hide behind menus |
| Trend chasing risk | Medium | Not a brainrot clone — good; combat MVP is harder to ship |
| Differentiation | Good | Extract greed + vertical climb + co-op combat is clear |
| Week-1 feasibility | Good if scoped tightly | 1 melee + 1 ranged + few powers, one tower |

## Keep (do not cut)
- Cash-out vs climb after each floor
- Under-20-minute target session
- Co-op 1–4
- Random upgrade per floor
- Boss at top
- No paywall on first win
- One tower for MVP

## Bake into MVP (agreed with game dev)
1. **First-60s action** — spawn into fighting fast; cash-out UI visible early.
2. **Extract moments** — readable win/lose for social clips later.
3. **Dead-player spectate** — intentional co-play signal.

## Cut / defer from v1
| Idea | Call | Why |
|---|---|---|
| Heist mode | Defer | Second fantasy before D1 is proven |
| Seasons / more towers | Defer | LiveOps after retention |
| Deep permanent unlock trees | Light only later | Avoid anime-RPG grind for v1 |
| Daily seeded tower | Post-MVP (approved) | Great friend co-play; not week-1 |
| Heavy monetization | Later | Protect first-win and retention |

## Reshape guidance (ongoing)
- Title/description/genre must match gameplay (no Robux-bait; accurate Action/Survival).
- Thumbnails show **real climb/combat/extract**, not fake UI.
- Ads only after bounce/D1 look competitive — RFY organic does not get boosted by ad traffic metrics.

## Official comps (feel, not clones)
Short survival / round action + extract tension (e.g. MM2-style session length energy; RIVALS-level combat aspiration long-term — not week-1 parity).
